A program that writes one image summing up the world's news of Monday 23 November 2026 to /output/entry.png. The image is a front page: COP31 ends without a deal in Antalya, a Russian drone destroys an apartment in Dymer near Kyiv, drones hit homes and a UN building in Khartoum, BepiColombo probes reach Mercury, plus South Korea, Indonesia and the USA in the ticker.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
